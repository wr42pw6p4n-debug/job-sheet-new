# R Key Engineering Job Manager

This is the installable PWA package for the R Key Engineering job manager.

## Files
- `index.html` — the app
- `manifest.webmanifest` — app/install metadata
- `sw.js` — offline cache/service worker
- `icon-192.png` / `icon-512.png` — app icons

## GitHub upload
1. Open the `r-key-engineering-job-manager` repository.
2. Tap **Add file** → **Upload files**.
3. Upload all five files from this folder.
4. Commit directly to `main`.

## GitHub Pages
Open **Settings** → **Pages**.
Under **Build and deployment**, choose **Deploy from a branch**.
Choose branch **main** and folder **/(root)**, then **Save**.

GitHub Pages will provide the site address.

## iPad installation
Open the published site in Safari.
Tap **Share** → **Add to Home Screen**.
Choose **Open as Web App** if shown, then **Add**.

Important: GitHub Pages sites are web sites. Do not put passwords, API keys, or other secrets in this repository.
